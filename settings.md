# Settings

## About Phone

- Click the `MIUI Version (For POCO)` button multiple times, until I get an alert stating I am a developer

## Security Status

- Set the `Find Device` setting to `Off`

## WiFi

- Connect to the WiFi

## Bluetooth

- Set it too off

## Portable hotspot

- Set it to off

## Connection & sharing

- Disable `NFC`

## Lock Screen

- Set `Sleep` to `2 minutes of inactivity`
- Disable `Rise to wake`
- Disable `Double tap to wake or turn off screen when device is locked`
- Disable `Wake lock screen for notifications`
- Disable `Wallpaper Carousel`
- Set the `Lock screen layout` so that the time is in the top center of the screen on one line on the top row and the day and date are on one line underneath
- Set the `Lock screen owner info` to my name
- Enable `Show signature on the lock screen`
- Enable `Display charging animation after device is unlocked`
- Disable `Launch camera`
- Enable `Pocket mode`

- ## Display & Brightness

- Set `Colour Scheme` to `Light mode`
- Disable `Automatic Brightness`
- Disable `Sunlight Mode`
- Disable `Reading Mode`
- Set the `Colour Scheme` to `Vivid`
- Set the `Refresh Rate` to `60 Hz`
- Set the `Font Settings` to `Default`

## Sound & Vibration

- Select the `Notification` sound
  - Select `Choose local ringtone`
  - Set it to [notification-sound.mp3](./notification-sound.mp3)
- Select the `Ringtone` sound
  - Select `Choose local ringtone`
  - Set it to [ringtone-sound.mp3](./ringtone-sound.mp3)
- Select the `Alarm` sound
  - Select `Choose local ringtone`
  - Set it to [alarm-sound.mp3](./alarm-sound.mp3)
- Set the `Alarm` sound to `Roar`
- Enable `Adjust media sound in multiple apps`
- Enable `Multiple audio sources`
- Enable `Allow speaker sound`
- Disable `Silent mode`
- Enable `Silence Media in Silent mode`
- Disable `Do not disturb`
- Disable `Schedule turn on time`
- Disable `When device is locked`
- Set `Notify about calls` to `None`
- Disable `Notify about repeated calls`
- Enable `Vibrate for calls`
- Disable `Vibrate in silent mode`
- Set `Vibrate on tap` to `Strong`

### Additional Settings

- Disable `Dial pad tones`
- Disable `Tap sounds`
- Enable `Play sound when locking device`
- Enable `Play sound when taking screenshots`
- Enable `Play sound when uninstalling apps`
- Enable `Play sound when deleting items`
- Enable `Play sound when charger is connected`
- Disable `Play audio at startup`
