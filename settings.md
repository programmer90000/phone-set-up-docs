# Settings

## About Phone

- Click the `OS Version (For POCO)` button multiple times, until I get an alert stating I am a developer

## Security Status

- Set the `Find Device` setting to `Off`

## WiFi

- Connect to the WiFi

## Bluetooth

- Set it too off

## Mobile Network

- Disable `Mobile Data`

### Data Roaming

- Disable `Data Roaming`

## Interconnectivity

- Disable `Xiaomi Interconnectivity`

## Portable Hotspot

- Disable `Portable Hotspot`
- Enable `Turn off hotspot automatically`
