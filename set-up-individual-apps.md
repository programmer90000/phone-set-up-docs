# Set Up Individual Apps

## Amazon Shopping

- Sign in

## Bing

- Sign in
- Click on the user icon in the top left of the screen
- Click `Settings`
- Select `Homepage`
  - Enable `Set the Bing image of the day as background`
- Select `Notifications`
  - Disable all notifications
- Select `Theme`
  - Set it to `Dark`
- Select `Search`
  - Disable `Private mode`
  - Set `Safe search` to `Moderate`
  - Disable `You might like`
  - Disable `Trending`
  - Disable `Read results aloud`
  - Disable `Contribute voice clips`
  - Disable `Images feed personalisation`

## Brave

- Select `Settings`

### Brave Shields & Privacy
- Set `Block trackers & ads` to `Standard`
- Enable `Auto-redirect AMP pages`
- Enable `Auto-redirect tracking URLs`
- Set `Upgrade connection to HTTPS` to `Default`
- Disable `Block JavaScript`
- Set `Block Cookies` to `Block third-party cookies`
- Enable `Block fingerprinting`
- Enable `Prevent fingerprinting via language settings`
- Disable `Store contact information for future broken site reports`
- Disable `Forget me when I close this site`
- Disable `Clear data on exit`
- Enable `Allow Facebook logins and embedded posts`
- Enable `Allow Twitter embedded posts`
- Disable `Allow LinkedIn embedded posts`
- Enable `Allow app links to open in apps outside of Brave`
- Set `Safe browsing` to `Standard`
- Enable `Allow screenshots in private tabs`
- Disable `Lock private tabs when you leave brave`
- Disable `Allow sites to check if you have payment methods saved`
- Set `Use secure DNS` to `Automatic`
- Enable `JavaScript optimisation and security`
- Disable `Block switch to app notices`
- Enable `Send a do not track request`
- Disable `Close tabs on exit`
- Disable `Allow privacy-persevering product analysis`
- Disable `Automatically send diagnostic reports`
- Disable `Automatically send daily usage ping to Brave`
- Disable `Allow Brave surveys`

### Brave News

- Disable Brave News

### Brave Wallet

- Disable `Default Ethereum wallet`
- Disable `Default Solana wallet`
- Set `Automatically lock Brave wallet` to `1 minute`
- Enable `Display Web3 notifications`
- Disable `NFT discovery

### Leo AI

- Enable `Show autocomplete suggestions in address bar`
- Enable `Show in quick search suggestions bar`
- Enable `Store my conversation history`
- Set `Default model for new conversations to `Automatic`

### Search Engines

- Set the `Standard tab` to `Brave`
- Set the `Private tab` to `Brave`
- Disable the `Quick Search Bar`
- Enable `Show browser suggestions`
- Enable `Show search suggestions`
- Enable `Index other search engines`
- Disable `Web Discovery Project`

### Homepage

- Enable the homepage
- Set it to `Brave's homepage`

### Privacy Report

- Disable `Privacy Report`
- Disable `Privacy report notification`

### Site Settings

- Set `Camera` to `Blocked`
- Set `Microphone` to `Blocked`

- Set `Motion Sensors` to `Blocked`
- Set `NFC Devices` to `Blocked`
- Set `USB` to `Ask First`

- Set `File Editing` to `Ask First`
- Set `Clipboard` to `Ask First`
- Set `Virtual Reality` to `Blocked
- Set `Agumented Reality` to `Blocked`
- Set `Third-party cookies` to `Block third-party cookies`
- Set `JavaScript` to `Allowed`

- Set `On-device site data` to `Sites can save data on your device`
